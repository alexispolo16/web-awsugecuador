User Groups y Student Builder Groups

Los AWS User Groups son comunidades abiertas a cualquier persona interesada en Amazon Web Services: profesionales, estudiantes y curiosos de la nube. Organizan meetups, talleres y eventos como el AWS Community Day.

Los AWS Student Builder Groups son comunidades universitarias lideradas por estudiantes, para aprender AWS y cloud desde la universidad.
